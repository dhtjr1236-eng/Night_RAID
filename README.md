# ⚔️ NIGHT RAID : beat boss(Unity 6 URP)

> **전술 전장을 Unity 6 URP로 완벽 재현한 3D 슈팅 액션 게임입니다."**

---

## 🎮 프로젝트 소개 (About)
본 프로젝트는 웹 기반(Three.js) 전술 무기 액션 프로젝트를 **Unity 6 (Universal Render Pipeline)** 환경으로 포팅 및 고도화한 작품입니다. 플레이어는 CSO의 강력한 초월 무기들을 장착하고, 야구 선수 모티브의 강력한 보스들과 다채로운 전장에서 사투를 벌이게 됩니다.

---

## ✨ 주요 특징 (Key Features)

### 🔫 1. CSO 초월 & 에픽 무기 아스널
* **Primary (주무기):** AK-47 Paladin (홀리 실드), M4A1 Dark Knight (다크 빔 관통포), M134 Minigun ONI (오니 장갑 전개 & 3초 경직 레이저)
* **Secondary (보조무기):** D-Eagle Crimson Hunter, Dual Beretta Gunslinger (패닝 난사)
* **Melee (근접무기):** DualSword Phantom Slayer (공간 절단), Warhammer Storm Giant (대지 분쇄)

### ⚾ 2. 개성 만점 보스 시스템 (Two-Way Bosses)
* **#17 Shohei Ohtani (오타니 쇼헤이):** 160km/h 패스트볼, 스위퍼 투구, 투타 겸업 추격 패턴
* **#51 Jung Hoo Lee (이정후):** 바람의 손자 근접 추격, 오라클 돌풍(이동속도 감소), 꽈당 패턴

### 🗺️ 3. 전술 전장 및 상호작용 오브젝트
* **Valley of the End :** 거대 석상, 번개 플래시가 치는 폭우 속 격전지
* **Dust2 Largo & Mini Arena:** 클래식 택티컬 레인 및 원형 아레나 난타전
* **인터랙티브 기믹:** 차크라 상승 기류(점프 패드), 연쇄 폭발하는 기폭찰 배럴, 차크라 체력 회복 성소, 이중 문(Double Door) 및 사다리 등반 시스템

## 🕹️ 조작 방법 (Controls)

| 키(Key) | 동작 (Action) |
| :--- | :--- |
| **W, A, S, D** | 이동 (Movement) |
| **Space** | 점프 / 등반 탈출 |
| **Shift** | 대시 (Dash) |
| **마우스 좌클릭** | 사격 / 근접 공격 (Primary Attack) |
| **마우스 우클릭** | 무기별 특수 스킬 (Special Skill) |
| **1, 2, 3** | 무기 슬롯 변경 (Primary / Secondary / Melee) |
| **R** | 재장전 (Reload) |
| **V** | 1인칭 / 3인칭 시점 전환 (옵션: 마우스 휠 거리 조절) |
| **H** | 보스 상태창 ON / OFF 토글 |

## 🛠️ 기술 스택 (Tech Stack)
* **Engine:** Unity 6 (6000.6.6f1)
* **Render Pipeline:** Universal Render Pipeline (URP)
* **Input System:** Unity Input System
* **Core Architecture:** Component-based C#, Object Pooling, Custom Collision & AABB Resolver

---

## 🚀 시작하기 (Getting Started)
1. 이 리포지토리를 클론(Clone)하거나 다운로드합니다.
2. **Unity Hub**를 통해 유니티 6 (6000.6.6f1 이상) 버전으로 프로젝트를 엽니다.
3. `Assets/NightRaid/Scenes` 또는 `Tools > Night Raid > Create Demo Scene`을 통해 데모 씬을 로드합니다.
4. 상단의 **Play (▶)** 버튼을 눌러 게임을 플레이합니다!
